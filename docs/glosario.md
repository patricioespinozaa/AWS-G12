# Glosario

| Término | Significado |
|---|---|
| **ACG** | *Adjusted Clinical Groups*: sistema de ajuste de riesgo poblacional que ya calcula la red asistencial |
| **APS** | Atención primaria de salud |
| **CESFAM** | Centro de Salud Familiar (atención primaria) |
| **CIE-10** | Clasificación Internacional de Enfermedades, 10.ª revisión; en Chile la mantiene el DEIS |
| **Consulta nueva** | Primera atención de especialidad por una interconsulta |
| **Control** | Atención de seguimiento indicada tras una consulta |
| **Causal de egreso** | Motivo por el que una solicitud sale de la lista de espera |
| **DEIS** | Departamento de Estadísticas e Información de Salud, del MINSAL |
| **ERC** | Enfermedad renal crónica |
| **FONASA** | Fondo Nacional de Salud (seguro público), con tramos A a D |
| **GES** | Garantías Explícitas en Salud (ex AUGE): problemas de salud con plazos de atención garantizados por ley |
| **HLF** | Hospital Clínico Dra. Eloísa Díaz La Florida |
| **HTA** | Hipertensión arterial |
| **ISAPRE** | Institución de Salud Previsional (seguro privado) |
| **Lista no GES** | Lista de espera de problemas sin garantía GES, donde no hay plazo legal de atención |
| **MINSAL** | Ministerio de Salud de Chile |
| **Previsión** | Sistema de seguro de salud del paciente (FONASA, ISAPRE u otro) |
| **RCE** | Registro clínico electrónico (ficha clínica electrónica) |
| **SIC** | Solicitud de interconsulta: documento de derivación de APS a especialidad |
| **SSMSO** | Servicio de Salud Metropolitano Sur Oriente |
| **κ (kappa)** | Coeficiente de concordancia entre evaluadores, corregido por el azar |
